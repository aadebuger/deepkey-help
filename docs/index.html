DeepKey 安装说明

DeepKey 插在你家的电脑上，你在外面用手机或电脑的浏览器，就能远程操作那台电脑的键盘和鼠标。

准备两个接口① 配置 WiFi ② 接被控电脑③ 远程控制在家直连 控制页用法常见问题安全须知

先看一眼：只要三步

① 配置 WiFi用数据线把 DeepKey 接到任意一台电脑，在网页里填 WiFi 和绑定码。
② 接被控电脑把 DeepKey 插到你想远程控制的那台电脑上。
③ 远程控制在外面打开你的专属网址，就能操作那台电脑。

需要准备

  • DeepKey 设备和 USB-C 数据线
  • 一台电脑，装有 Chrome 或 Edge 浏览器（配置时用）
  • 家里的 2.4G WiFi 名称和密码
  • 卖家给你的 绑定码（6 位数字）和 专属网址
配置只需要做一次。以后换了 WiFi 或者要转给别人用，再按第 ① 步重新配置即可。

认识两个接口

DeepKey 有两个 USB-C 口，用途不同，插错了不会损坏，但功能用不了：

接口接到哪里作用
COM配置用的电脑配置 WiFi、绑定码、设备名。配置完可以拔掉
USB要被控制的电脑DeepKey 在这台电脑上就是一套键盘和鼠标，同时由它供电
接口旁边印有 COM 和 USB 字样。如果外壳挡住看不到，可以问卖家，或者看第 ① 步：网页能连上的那个口就是 COM 口。

1配置 WiFi 和绑定码

  1. 用数据线把 DeepKey 的 COM 口 接到电脑上。
  2. 用 Chrome 或 Edge 打开配网页：
    打开 DeepKey 配网页
    如果卖家给你发的是带绑定码的链接（网址末尾有 ?bind=），直接打开那个链接，绑定码会自动填好。
  3. 点「连接设备」，浏览器会弹出串口列表，选 DeepKey 那一项后点「连接」。
    • Windows 上一般叫「USB 串行设备 (COMx)」或「USB-Enhanced-SERIAL CH343」
    • Mac 上一般叫 wchusbserial… 或 usbmodem…
  4. 连上后页面会显示设备编号和当前状态。依次填写：
    • WiFi 名称和密码：必须是 2.4G WiFi（名字里带 5G 的一般不行）
    • 绑定码：卖家给你的 6 位数字
    • 设备名称：随便起，比如「书房电脑」，会显示在你的设备列表里
  5. 点「保存」。等十几秒，页面会自动刷新状态。看到「✅ 设置完成，设备已经在线」就成功了。

页面上的「测试键盘」按钮会在 USB 口所接的电脑上输入 hello，可以用来确认键盘是通的（需要那台电脑上有个能打字的地方，比如记事本）。

2接到要控制的电脑

  1. 把 DeepKey 的 USB 口 插到要远程控制的电脑上。
  2. 电脑会把它识别成一套键盘和鼠标，不需要装任何软件或驱动。Windows 第一次插上可能会"叮"一声，属于正常。
  3. DeepKey 由这台电脑供电，插上后十几秒内会自动连上 WiFi 和服务器。
如果配置时用的就是这台电脑，配置完拔掉 COM 口那根线即可，USB 口那根一直插着。
被控电脑要保持开机。电脑睡眠或关机时，USB 键鼠一般不起作用。建议在系统设置里关掉自动睡眠，或者设置成"按键盘可唤醒"。

3在外面远程控制

  1. 用手机或电脑的浏览器打开卖家给你的专属网址（形如 http://服务器地址/u/一串字符）。
  2. 页面会列出你名下的设备，以及是否在线。
  3. 点设备名，进入控制页，会自动连接，然后就可以操作了。
收藏这个网址。手机上可以用浏览器菜单里的「添加到主屏幕」，以后像打开 App 一样点一下就行。
专属网址就是你的钥匙：拿到这个网址的人都能控制你的设备，不要发给别人。如果不小心泄露了，联系卖家换一个，旧网址立即失效。

在家里直接连（不经过服务器）

手机或电脑和 DeepKey 连着同一个 WiFi 时，可以直接连设备，速度更快，服务器连不上时也能用：

  • 设备列表里在线的设备下面会显示「在家(同一 WiFi)可直连」的地址，点它就行；
  • 或者直接打开 http://deepkey-xxxxxx.local/（xxxxxx 是设备编号的后 6 位，配网页上能看到）；
  • 部分安卓手机打不开 .local 地址，这时用 IP 地址，比如 http://192.168.1.50/，配网页上也会显示。
同一个 WiFi 下的人都能打开这个直连页面并控制键鼠，但改不了设备的设置（WiFi、绑定码只能通过 COM 口改）。

常见问题

点「连接设备」后，列表里找不到 DeepKey
  • 确认插的是 COM 口，并且数据线能传数据（有些线只能充电，换一根试试）。
  • Windows 10/11 一般自动识别，不用装驱动。如果设备管理器里出现带黄色感叹号的设备，安装 CH343 串口驱动：WCH 官网搜索 CH343，下载 Windows 版 CH343SER 安装后重新插线。
  • 必须用 Chrome 或 Edge（电脑版）。Safari、Firefox 和手机浏览器不支持网页串口。
显示「设备没有回应」
  • 确认插的是 COM 口，不是 USB 口。
  • 拔掉 COM 口的线，等 3 秒再插上，然后重新点「连接设备」。
  • 还不行就点「刷新状态」，或联系卖家。
WiFi 一直「连接中」
  • DeepKey 只支持 2.4G WiFi。路由器如果是"双频合一"，可以在路由器设置里单独开一个 2.4G 名称。
  • 核对 WiFi 名称和密码，注意大小写。
  • 不支持需要网页登录的 WiFi（酒店、公司访客网络那种）。
  • 设备离路由器太远也会连不上，换个近一点的位置试试。
设备列表里显示「离线」
  • 被控电脑是否开着？DeepKey 是从 USB 口取电的，电脑关机后 DeepKey 也会断电。
  • 家里的 WiFi 或宽带是否正常？
  • 换过 WiFi 名称或密码？需要按第 ① 步重新配置。
显示在线，但操作后被控电脑没反应
  • 页面顶部「HID」显示「未就绪」：说明 USB 口没插好，或者被控电脑在睡眠。把 USB 口那根线重新插一下，或者先唤醒电脑。
  • 拖动、打字没反应：确认「🎯 捕获键鼠」是「开」，并且被控电脑上有个能输入的窗口在前台。屏幕键盘和鼠标按钮不需要打开捕获。
  • 输入的是英文，不是中文：打字走的是键盘按键，中文需要在被控电脑上切换输入法后用拼音输入。
有个键好像一直按着

点控制页上的「全松」。如果页面打不开，等 1–2 秒，设备检测到网络断开会自动全部松开。

鼠标移动有延迟或一卡一卡的
  • 远程控制要经过服务器，网络差的时候会有延迟。手机信号或 WiFi 不好时比较明显。
  • 在家时用「在家直连」会快很多。
换了 WiFi / 搬家了

按第 ① 步重新连接配网页，填新的 WiFi 名称和密码后保存即可。绑定码留空，设备还是你的。

要把设备转给别人用

请联系卖家拿新用户的绑定码，按第 ① 步填进去保存。保存成功后设备就到了新用户名下，原来的专属网址里就看不到它了。

安全须知

  • 专属网址 = 钥匙。不要截图发群、不要发给不认识的人。泄露后联系卖家更换。
  • 远程控制能做你在键盘鼠标上能做的所有事情。离开电脑前，建议锁屏（被控电脑上的登录密码仍然有效）。
  • 同一个 WiFi 下的人可以打开"在家直连"页面。如果家里 WiFi 有不信任的人在用，建议给访客单独开一个访客网络。
  • 设备的 WiFi、绑定码等设置只能用数据线插 COM 口修改，远程和网页都改不了。
