DeepKey 设置

给设备配 WiFi，并绑定到你的账号。只需要做一次。

这个浏览器不能连接设备。

请用电脑上的 Chrome 或 Edge 打开本文件(手机浏览器、Safari、Firefox 都不行)。

1连接设备

用 USB 线把设备的 COM 口插到这台电脑，点下面的按钮，在弹出的列表里选它(名字通常带 usbserial、CH34x 或 CP210x)。

2填写设置

高级:服务器地址

3设备状态

还没连接设备

✅ 设置完成，设备已经在线。

现在可以拔掉这根 USB 线(设备另一个 USB 口保持接在被控电脑上)。以后打开你的专属网址，就能远程操作。

出问题了?
  • 点「连接设备」没有反应 / 列表里没有设备:换一根能传数据的 USB 线;Windows 可能需要装 CH340 或 CP210x 驱动。
  • WiFi 一直连接中:检查密码;5G WiFi 不行,要用 2.4G。
  • 连不上服务器:联系提供设备的人确认服务器地址。
  • 绑定码无效:检查 6 位数字;设备恢复过出厂需要重新填绑定码。
